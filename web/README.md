# УБ Автобус – Ирэх цаг

Улаанбаатарын автобусны ирэх цагийг харах демо веб апп.

## Ажиллуулах

```bash
cd web
npm install
npm run dev
```

Дараа нь [http://localhost:3000](http://localhost:3000) дээр нээнэ үү.

## Функц

- Зогсоол хайх (нэр эсвэл ID, debounce)
- Дуртай зогсоолууд хадгалах (localStorage)
- Газрын зураг дээр зогсоолын байршил
- Сонгосон зогсоолд ирж буй автобусуудын жагсаалт
- Ирэх хугацаа (минут), ирэх цагаар эрэмбэлсэн, өнгөөр ялгасан
- Шинэчлэх товч, 30 сек тутам автомат шинэчлэлт
- Оффлайн мэдэгдэл

## API

Өгөгдөл нь USCC (app.uscc.mn) API-аас ирнэ. CORS-ийг Next.js API Routes-аар proxy хийнэ.
